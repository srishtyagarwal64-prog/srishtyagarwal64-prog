## 🚀 Featured Projects

### 🤖 1. Prepnexa — AI Interview Platform

An AI-powered interview preparation application designed to help candidates practise interviews and review their performance.

- Generates interview questions based on role, experience, and interview type.
- Supports interactive interview sessions with speech-based features.
- Provides interview performance reports.
- Includes credit-based usage and Razorpay payment integration.

**Tech Stack:** React, JavaScript, Node.js, Express.js, MongoDB, AI APIs, Razorpay.

### 💬 2. Vaarta AI — Embedded Website Chatbot

An AI chatbot designed to integrate into websites and let visitors interact with an AI assistant.

- Provides an embeddable website chat widget.
- Uses an LLM API to generate responses.
- Supports website question-answering functionality.
- Manages conversations and messages through backend APIs.

**Tech Stack:** React, JavaScript, Node.js, Express.js, MongoDB, Groq API.
